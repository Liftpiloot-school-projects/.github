# 🎓 Fontys ICT — School Projects

This organization contains projects, assignments, and coursework completed as part of the **HBO ICT Software Engineering** program at **Fontys University of Applied Sciences**.

Repositories in this organization represent a range of **individual** and **team-based** work, primarily focused on **backend development**, **software design**, and **web technologies**.
